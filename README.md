# SettleRight

SettleRight helps small finance and operations teams compare expected payments against provider settlement records, identify discrepancies, and resolve exceptions with a traceable history.

This repository is a learning project: a modular Spring Boot monolith with PostgreSQL, built in small verified steps.

## Current status

Milestone 0 is complete. A minimal Spring Boot 4.1.1 application starts on port 8080. No product features yet.

## Local requirements

- Java 25 LTS
- Git
- Docker Desktop (WSL 2 backend)

## What this project is not

Not a payment processor, bank ledger, or full accounting system. First release uses synthetic data only.
